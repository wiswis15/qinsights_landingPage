If an import or analysis stops working as expected, the quickest first step is usually to refresh the page and try again. In many cases, the problem is a temporary connection issue rather than a problem with your project.

## Common Issues

### An Analysis or Import Is Stuck at 0%

Refresh the page using your browser's reload button. If the issue continues, try again later or contact support.

### An Error Message Appears During Import or Analysis

This is often caused by a brief internet interruption. Wait a few seconds and try again. If the error persists, it may be a real bug and should be reported.

### No Preview Appears After Uploading a Document

If the upload was interrupted, the summary preview may never appear. Delete the document and upload it again rather than continuing to work with a file that has no preview.

### Q Refuses to Answer

This often happens when your question triggers a language-model safeguard outside QInsights' control. Rephrasing the question usually resolves it.

### Repeated Error Messages Continue to Appear

If you keep seeing repeated errors across several actions, log out and back in again. If the problem persists, contact support.

## Support

You can contact the support team at support@qinsights.ai. If you are working inside a Conversational Analysis chat, you can also use the support icon to open a help request directly from the app.

For answers to common questions, see [Frequently Asked Questions](/docs/faq) and [Resources](/docs/resources).
