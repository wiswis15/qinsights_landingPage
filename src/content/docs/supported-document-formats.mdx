QInsights currently supports the following document formats:

| Format | Extensions | Notes |
| --- | --- | --- |
| Audio and video | `.mp3`, `.m4a`, `.mp4` | Up to 1 GB |
| Text | `.docx` | |
| PDF | `.pdf` | |
| Excel | `.xlsx`, `.csv` | `.xlsx` recommended |

When you upload an audio or video file, QInsights transcribes it - see [Transcribing Audio or Video Files](/docs/transcribing-audio-or-video-files). When you analyze the data, you'll be analyzing the text transcript, with access back to the source recording.
