To add documents to your project, click **Upload New File**.

<figure className="docs-article__figure">
  <img className="docs-article__inline-image docs-article__inline-image--compact" src="/docs/20.png" alt="Adding documents to a project - Upload New File and the Project Files list." />
  <figcaption className="docs-article__figcaption">Adding documents to a project - Upload New File and the Project Files list.</figcaption>
</figure>

You'll then see two options:

<figure className="docs-article__figure">
  <img className="docs-article__inline-image" src="/docs/21.png" alt="Select transcription language or speaker detection if applicable." />
  <figcaption className="docs-article__figcaption">Select transcription language or speaker detection if applicable.</figcaption>
</figure>

1. **The first option** applies when you add audio or video files for transcription. You can either let the system auto-detect the language or select one of 18 preset languages. Selecting a preset language improves the accuracy of the transcription. See [Transcribing Audio or Video Files](/docs/transcribing-audio-or-video-files).
2. **The second option** relates to uploading transcripts for interviews or focus groups prepared elsewhere. Switch on **Detect Speakers** (see [Preparing Documents for Analysis - Transcripts Created Elsewhere](/docs/preparing-transcripts-created-elsewhere) for how these documents need to be formatted). See [Adding Transcripts Created Elsewhere](/docs/adding-transcripts-created-elsewhere).

Make a selection if applicable and click **Proceed**, then select the file(s) to upload.

For reports, notes, or articles in Word or PDF format that aren't a multi-speaker transcript, and for spreadsheet-based survey data, neither option applies - there's nothing to transcribe or detect. See [Adding Reports, Notes, etc. in Word or PDF Format](/docs/adding-reports-word-or-pdf) and [Adding an Excel File](/docs/adding-an-excel-file).

> **Note:** QInsights currently transcribes one audio or video file at a time.

## Next Steps

Once your files are uploaded, continue to [Project View After Data Are Uploaded](/docs/project-view) to see how uploaded documents are displayed and managed.
