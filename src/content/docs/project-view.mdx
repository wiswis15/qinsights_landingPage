Once your files are uploaded, each one appears as a document card in the project view. The card shows the file name, basic metadata, and a small set of actions for reviewing or managing the document.

## Document Cards

Each document card gives you a quick overview of the uploaded file. Depending on the file type, you may see a summary preview, a quick action menu, or the option to open a read-only view.

For Word, PDF, and Excel files, the three-dot menu usually lets you:

- preview the file
- rename the document
- view detected speakers for transcripts where available

For transcripts, you can also review and edit the transcript text directly.

## Summary Previews

A summary preview helps you confirm that a document was imported correctly. If the summary button looks faded or missing, the upload may have failed or been interrupted. In that case, delete the document and upload it again rather than continuing to work with a file that has no usable preview.

## Deleting Project Documents

- **Single document:** click the bin icon on its document card.
- **Multiple documents:** select the checkboxes on the documents you want to remove, then click the bin icon in the action toolbar above the file list.

## Sorting Documents

Use the sort controls above the document list to change how files are displayed - handy in larger projects with many uploaded files:

- **Name (A–Z)** - alphabetical order; click again to reverse to Z–A.
- **Date (Newest / Oldest)** - most recently uploaded first; click again to reverse the order.

## Keep Survey Data in Its Own Project

Excel data is processed differently from Word, PDF, audio, or video files and can't be combined with them in a single analysis. Keeping spreadsheet-based data in its own project also keeps [Data Context](/docs/data-context) manageable, since every imported column becomes a variable and a file with many columns can otherwise make the setup complex quickly.

## Next Steps

Once the project view feels clear and your files are in place, move on to [Data Context](/docs/data-context) so QInsights can interpret your documents and respondents correctly.
