QInsights supports most of the languages commonly used in qualitative research. The platform can usually detect the language of your source material automatically, but the way it responds depends on the type of analysis you run.

## Automatic Language Recognition

When you upload a document, QInsights detects the language of the source text automatically. For analyses that do not rely on a direct user prompt - such as a summary or a theme analysis - the output is generally produced in the language of the source document.

For example:

- a Spanish document usually produces Spanish themes or a Spanish summary
- an English document usually produces an English summary
- a German document usually produces German themes

## Prompted Analysis

For analyses that involve a direct prompt, such as Conversational Analysis, the response usually follows the language of your prompt. If your source text is in English but you ask a question in German, QInsights will usually answer in German while still analyzing the English material.

This can be useful when you work with data in one language but want to discuss or report your findings in another.

## If the Output Appears in the Wrong Language

If QInsights returns an answer in the wrong language, simply ask a follow-up prompt such as:

> Please write the answer in German.

## Use the Project Description With Intent

The project description is treated as contextual information about your project and should describe the study, the data, or your research focus. It should not be used for unrelated instructions such as personal reminders, because that can confuse later summaries or analysis.

For setup details, see [Creating a Project](/docs/creating-a-project).
